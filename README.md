# UMD Undergraduate Admissions Homepage Recreation

A responsive, static front-end recreation of the University of Maryland Undergraduate Admissions homepage at [admissions.umd.edu](https://admissions.umd.edu/).

**Live demo:** [jiayukang0414.github.io/umd-admissions-clone](https://jiayukang0414.github.io/umd-admissions-clone/)

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

## Included

- Responsive desktop and mobile layouts
- Local copies of the public homepage imagery and hero video
- Accessible navigation and dropdown interactions
- Pause/play control for the hero video
- All content links route to the official UMD Admissions website
